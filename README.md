### What I'm building right now

**[Xích Lô Đó Đây](https://xichlododay.com)** — a self-initiated AI content-production tool. You
give it an idea; it writes the script, turns the script into narration and imagery, and composes
the result into a finished video.

| | |
|---|---|
| Front end | Next.js App Router, TypeScript, Tailwind |
| Video | Remotion, rendered on AWS Lambda |
| Speech | Microsoft Edge Neural TTS, plus local models on Apple Silicon |
| Text & images | Gemini, Pollinations |
| Hosting | Vercel |

It is not a demo that runs once for a screenshot. I use it to produce the videos I publish on my
own page, which means every rough edge gets found the honest way — by needing the output, not by
testing for it.
